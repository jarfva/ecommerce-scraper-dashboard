* **Project Title:**
  `Automated E-Commerce Scraper & Market Intelligence Dashboard`
* **Role:**
  `Full-Stack & Python Automation Developer`
* **Deliverables:**
  `Web Scraping, Data Extraction, Excel Formatting, Interactive Dashboard`
* **Tools / Technologies:**
  `Python, BeautifulSoup, Pandas, OpenPyXL, Tailwind CSS, Chart.js`
* **Project Overview / Description:**
  ```text
  Built an automated end-to-end data extraction and reporting pipeline designed to eliminate manual competitor research for e-commerce brands.

  Key Achievements & Features:
  • Multi-Page Crawling: Engineered robust scraping logic using Python and BeautifulSoup with polite crawl delays, custom user-agent headers, and automated error retries.
  • Clean Data Transformation: Processed unstructured HTML into standardized datasets (SKU, title, price, rating, stock status, and direct URLs) using Pandas.
  • Executive Excel Deliverable: Generated a corporate-styled Excel (.xlsx) report featuring KPI summary cards, rating breakdown analytics, freeze-panes, and auto-filters using OpenPyXL.
  • Interactive Web Dashboard: Developed a responsive dark-mode frontend with Chart.js and Tailwind CSS allowing non-technical stakeholders to search, filter, and visualize catalog data in real time.
  ```
